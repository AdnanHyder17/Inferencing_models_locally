# Inferencing Models Locally

A practical and structured repository for running and benchmarking Large Language Models (LLMs) locally using modern inference engines such as **llama.cpp**, **vLLM**, **Ollama**, **Hugging Face Transformers**, **TensorRT-LLM**, and **ExLlamaV2**.

---

## 🚀 Purpose

This repository is designed to help developers, engineers, and researchers run LLMs locally and understand trade-offs between different inference engines in terms of:

- Speed (tokens/sec)
- Latency
- Memory (RAM/VRAM) usage
- Quantization efficiency
- Hardware compatibility (CPU vs GPU)

It serves as a hands-on lab for experimenting with local inference setups.
